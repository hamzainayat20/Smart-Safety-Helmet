# Smart-Safety-Helmet

Final Year Project for an AI-assisted smart safety helmet. The system combines a Flutter application, Firebase backend, ESP32 sensor telemetry, and safety-risk inference.

## Getting Started

This repository contains the Flutter application together with its backend, firmware foundation, planning documents, tests, and inference service.
